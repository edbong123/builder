## Before you start

Before writing any code, run the diagnostic skill:

- Location: `skills/diagnose-agentsmd.md`
- Read the file and follow its instructions exactly

Then ask the user:

> Diagnostic ready. How do you want to proceed?
> A - Run diagnosis now
> B - Skip this time
> C - Ignore for this session

Wait for the user to respond before doing anything else.
If the user picks A, complete the full diagnostic and present the report.
If B or C, proceed directly to the task.
